# Images

`dashboard.png` should be a screenshot of the live dashboard, taken in Excel.

## How to capture it (about 30 seconds)

1. Open `dashboard/Coffee_Sales_Dashboard.xlsx` in Excel.
2. Go to the `Dashboard` sheet.
3. Take a screenshot of the full dashboard:
   - Windows: Win + Shift + S, then drag over the dashboard.
   - Mac: Cmd + Shift + 4, then drag over the dashboard.
4. Save it as `dashboard.png` in this folder, replacing the placeholder.

A real Excel screenshot is important: slicers, the timeline, and PivotCharts only render correctly inside Excel, so they cannot be captured automatically.
